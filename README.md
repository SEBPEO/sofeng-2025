# 🏥 Medical AI Notetaker

### Software Engineering Project — Faculty of Electrical Engineering and Computing, University of Zagreb (FER) in year 2025/2026

---

## 🎯 Project Description

**Medical AI Notetaker** is an AI-powered platform designed to assist doctors in managing patient interactions more efficiently and securely.  
The system records and transcribes doctor–patient conversations, automatically generates structured medical notes, and allows doctors to share summaries, diagnoses, and treatment plans with patients and other verified doctors.

This project was developed as part of the **Software Engineering** course at **FER**, with the goal of exploring **AI integration in healthcare**, **real-time communication systems**, and **secure data handling**.

### 🧠 Motivation
Modern healthcare professionals face increasing administrative workloads, especially during patient visits.  
Our motivation was to reduce the burden of manual note-taking and allow doctors to focus more on their patients, while ensuring data privacy and accuracy through AI-driven automation.

### 💡 Learning Goals
Throughout this project, our team aimed to learn and apply:
- Full-stack development using **React**, **Node.js**, and **PostgreSQL**
- Integration of **OpenAI APIs** for transcription and summarization
- Implementation of **OAuth 2.0** for secure authentication
- Designing scalable and privacy-compliant systems
- Team collaboration and agile development practices

---

## ⚙️ Functional Overview

**Core Features**
- 🔐 Secure Login (Google OAuth 2.0)
- 👨‍⚕️ Doctor & Patient Profiles
- 🎙️ Conversation Recording & AI Transcription
- 📝 AI-Generated Visit Summaries and Notes
- 💬 Real-Time Chat with Attachments
- 📅 Appointment Scheduling with Google Calendar Integration
- 🔔 Notifications for Appointments and Messages
- 🤝 Secure Note Sharing Between Doctors
- 🔒 Data Protection (GDPR & HIPAA-like compliance)

## 🧰 Technologies Used

| **Category** | **Technology** | **Role** |
|---------------|----------------|-----------|
| **Frontend** | React | Building the user interface and client-side interactivity |
| **Backend** | Node.js / Express | REST API, authentication, server logic |
| **Database** | PostgreSQL | Storing users, sessions, notes, and appointments |
| **AI Integration** | OpenAI API | Speech-to-text transcription and AI-generated summaries |
| **Authentication** | Google OAuth 2.0 | Secure login and user identity verification |
| **Scheduling** | Google Calendar API | Syncing appointments between doctor and patient |
| **Notifications** | Twilio / Firebase Cloud Messaging | Sending reminders and alerts |
| **Deployment (Planned)** | Docker / Render / Vercel | Hosting and scalability |
